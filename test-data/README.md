# Наборы данных

Все файлы — один `FeatureCollection` в EPSG:4326 в формате технического приложения (раздел 1): существующая сеть,
камеры, источник, перспективные ОКС с точками подключения, ограничения. «ОКС» в таблице — число точек
подключения (`oks_connection_point`), то есть сколько объектов сервис должен подключить. Итог — лучший
вариант расчёта с параметрами по умолчанию; время — сам расчёт по `started_at … finished_at`
(без загрузки и импорта), MacBook Apple Silicon, Docker, 2026-09-24.

## Как завести в сервисе

После запуска сервис пуст. `python3 tools/seed_datasets.py` загружает четыре набора (ЗИЛ,
«ЗИЛ с окружением OSM», «Все правила на 6 ОКС», «Ошибки во входных данных»), `--all` — все из таблицы,
`--reset` — удалить всё и завести заново. Названия в сервисе — «Группа · Название» (префиксы Проект / Пример /
Нагрузка, в интерфейсе — группы «Проекты», «Примеры», «Большие наборы»); соответствие файлам — в списке `DATASETS`
в скрипте.

## `generated/`

Пустая папка в `.gitignore` для больших файлов, которые собираются на месте и в репозиторий не попадают:

```bash
python3 tools/gen_testdata.py large -o test-data/generated/large.geojson --bytes 3000000000   # 3 ГБ, ≈ 10 млн зданий
```

Так проверяется потоковый импорт (замеры — `docs/metrics.md`, раздел «3 ГБ»). Синтетические наборы из
таблицы пересобираются тем же `tools/gen_testdata.py` (команды — в шапке скрипта); как собраны наборы с OSM —
`docs/data.md`.
